# **App Name**: PromptForge AI

## Core Features:

- Idea Decomposition: Analyze user's idea using OpenAI to break it down into actionable steps, assigning the best platform (Firebase, Replit, Lovable, Blob) to each step, functioning as an AI tool.
- Prompt Generation: Generate copy-paste ready prompts optimized for each target platform using OpenAI.
- Prompt Display: Display platform-specific prompts in a card or timeline view.
- Copy Prompt: Enable users to copy generated prompts with a single click.
- Idea Input Form: Provide an input form for users to describe their project idea.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to evoke a sense of intelligence, technology, and reliability.
- Background color: Light gray (#F5F5F5), almost white, for a clean, modern, professional aesthetic.
- Accent color: Purple (#7E57C2) to create contrast and highlight key elements like copy buttons.
- Font pairing: 'Space Grotesk' (sans-serif) for headlines and short amounts of body text, 'Inter' (sans-serif) for longer body text.
- Use flat, minimalist icons related to each platform (Firebase, Replit, Lovable, Blob).
- Responsive layout to ensure usability across devices, featuring a clean, structured design.
- Subtle transition animations for prompts appearing and copying to clipboard to improve user experience.
